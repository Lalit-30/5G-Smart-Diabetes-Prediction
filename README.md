## Overview

5G-Smart Diabetes Prediction is a machine learning-based healthcare application developed to predict diabetes using patient medical records. The system evaluates multiple machine learning algorithms and compares their prediction accuracy to identify the most effective model for diabetes diagnosis.

The application demonstrates how data mining and machine learning techniques can assist healthcare professionals by enabling faster and more accurate disease prediction.

---

# Problem Statement

Early diagnosis of diabetes is essential for reducing long-term health complications.

Traditional diagnosis often depends on laboratory tests and expert analysis. This project automates the prediction process by analyzing patient attributes using multiple machine learning algorithms.

---

# Objectives

- Predict diabetes using patient medical records.
- Compare multiple machine learning algorithms.
- Improve prediction accuracy.
- Assist healthcare professionals in early diagnosis.
- Reduce manual prediction effort.

# Installation

Clone the repository

```bash
git clone https://github.com/Lalit-30/5G-Smart-Diabetes-Prediction.git
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
python Cloud/Cloud.py
```

or

```bash
python User/client.py
```

---

# Results

The system compares multiple machine learning algorithms and predicts whether a patient is diabetic.

Artificial Neural Network (ANN) achieved the highest prediction accuracy among the evaluated models.
